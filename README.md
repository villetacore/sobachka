# 🐶 Собачка — бот для поиска заказов на фрилансе

Бот следит за фриланс-биржами и досками заказов, отбирает заказы под ваши направления по ключевым
словам и собственной небольшой нейросети, а подходящие присылает в Telegram вместе с готовым
первым сообщением заказчику.

Платформа универсальная: ни площадки, ни направления в код не зашиты. Источники и профили
настраиваются в веб-интерфейсе под любую сферу — от разработки и дизайна до производства.

## Возможности

- Опрос любых площадок: RSS/Atom-ленты, HTML-страницы со списком заказов (в том числе вперемешку с рекламой)
  и JSON API. Как разбирать сайт, задаётся настройками источника, без программирования.
- Свой список готовых площадок (`config/presets.json`): источник добавляется в один клик.
- Оценка заказа по ключевым словам и собственной нейросети, которая дообучается сама: без внешних API и ручной разметки.
- Готовый первый отклик заказчику по шаблону профиля.
- Командная работа: пользователи, роли, личные уведомления в Telegram.

## Как это работает

```
   RSS / Atom · HTML-страницы · JSON API любых площадок
          │  (каждые 3–10 минут)
          ▼
 ┌─────────────────┐   /score, /train   ┌───────────────────────────────┐
 │  backend (Go)   │ ─────────────────▶ │ ml (Python + PyTorch)         │
 │ сбор, фильтры,  │                    │ • ключевые слова профилей     │
 │ отклик по       │                    │ • своя нейросеть (MLP),       │
 │ шаблону, API,   │                    │   дообучается сама            │
 │ Telegram-бот    │                    └───────────────────────────────┘
 └──────┬──────────┘
        │ PostgreSQL
        ▼
 ┌──────────────┐     ┌──────────────┐
 │ web (React)  │     │  Telegram    │
 └──────────────┘     └──────────────┘
```

1. **Сбор.** Go-сервис по расписанию опрашивает источники, новые заказы сохраняет (дубли отсекаются).
   Для HTML-источников описание подгружается со страницы заказа.
2. **Фильтры профиля:** минус-слова и минимальный бюджет.
3. **Оценка 0–100%** по каждому профилю, выбирается лучший:
   - **ключевые слова.** Слово ищется как начало слова («верстк» → «вёрстка», «верстку»),
     слова до 3 букв («seo», «cms») — только целиком, фраза — слова подряд («интернет магазин»).
     Совпадение в заголовке весит вдвое больше. Одно слово в описании — 55%, в заголовке — 80%, три совпадения — ~90%;
   - **своя нейросеть** на PyTorch: «мешок слов» заказа → маленький MLP. Без скачиваемых моделей и сторонних API.
     **Дообучается сама:** каждый новый заказ размечается по ключевым словам (явное совпадение — «подходит»,
     ни одного — «мимо», заказы соседних направлений — тоже «мимо»). При обучении сами ключевые слова из текста
     прячутся, поэтому сеть учит слова-спутники и по ним отличает настоящие совпадения от случайных
     («робот» в заказе на SEO-статьи) и поднимает спорные заказы, похожие на настоящие. Обучение — раз в 30 минут,
     если пришли новые заказы, ~30 секунд на CPU. Сеть уточняет только заказы, где есть хотя бы одно совпадение,
     её вес — до 40% по направлению. Оценки 👍/👎 необязательны: каждая весит как три авторазметки
     и поднимает вес сети до 70% после 30 оценок по направлению.
4. **Отклик** собирается из шаблона профиля. Подставляются название заказа и найденные в нём слова.
   Вариантов может быть несколько, кнопка «Другой вариант» переключает их.
5. **Telegram:** ссылка, бюджет, процент совпадения, найденные слова и отклик (нажмите на текст — он скопируется).
   Кнопки 👍 / 👎 обучают нейросеть, 🔄 меняет вариант отклика.

## Быстрый старт

Нужны Docker и Docker Compose (~1 ГБ RAM, ~2 ГБ на диске).

```bash
git clone https://github.com/villetacore/sobachka.git
cd sobachka
cp .env.example .env
# заполните ADMIN_PASSWORD, APP_SECRET_KEY (openssl rand -base64 32), PUBLIC_URL и POSTGRES_PASSWORD
docker compose up -d --build
```

Откройте `PUBLIC_URL`, войдите администратором, в «Настройки и ИИ» вставьте токен бота от @BotFather,
затем в «Мой аккаунт и Telegram» подключите свой Telegram. В «Источниках» добавьте площадки,
в «Профилях» — свои направления. Для локального запуска по HTTP:
`PUBLIC_URL=http://localhost:8088`, `COOKIE_SECURE=false`.
