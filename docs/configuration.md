# Переменные окружения

Задаются в `.env` (образец — [`.env.example`](../.env.example)). Большинство рабочих настроек — бот, уведомления,
порог, расписание — меняются потом в веб-интерфейсе и хранятся в БД.

## Обязательные

| Переменная | Описание |
|---|---|
| `ADMIN_USERNAME` | логин первого администратора, по умолчанию `admin` |
| `ADMIN_PASSWORD` | пароль первого администратора, 12–72 байта. Нужен только при пустой таблице пользователей |
| `APP_SECRET_KEY` | 32 случайных байта в base64: `openssl rand -base64 32`. Шифрует токен бота — сделайте резервную копию |
| `PUBLIC_URL` | внешний origin без пути и завершающего `/`, например `https://sobachka.example.com` |
| `POSTGRES_PASSWORD` | пароль PostgreSQL. Для существующего тома менять нельзя |

## Необязательные

| Переменная | По умолчанию | Описание |
|---|---|---|
| `COOKIE_SECURE` | `true` | `false` только для локального HTTP |
| `TELEGRAM_BOT_TOKEN` | — | импортируется при первом запуске, дальше бот настраивается в интерфейсе |
| `WEB_PORT` | `8088` | порт веб-интерфейса на хосте |
| `NOTIFY_MAX_AGE_MIN` | `360` | не уведомлять о заказах старше, минут |
| `RETRAIN_EVERY` | `10` | дообучить нейросеть сразу после стольких новых оценок 👍/👎 |
| `TORCH_THREADS` | `2` | потоков PyTorch в ML-сервисе |
| `SELF_TRAIN_INTERVAL_MIN` | `30` | как часто нейросеть проверяет, не пора ли дообучиться на новых заказах |
| `FETCH_USER_AGENT` | Chrome | User-Agent при опросе бирж |
| `FETCH_TIMEOUT_SEC` | `40` | таймаут опроса одного источника |
| `PRESETS_FILE` | `config/presets.json` (в Docker — `/config/presets.json`) | файл готовых площадок для кнопки «Готовые площадки», см. [источники](sources.md#готовые-площадки) |

## Внутренние (задаются в docker-compose)

| Переменная | Описание |
|---|---|
| `DATABASE_URL` | строка подключения к PostgreSQL |
| `ML_URL` | адрес ML-сервиса, `http://ml:8000` |
| `HTTP_ADDR` | адрес backend, `:8080` |
| `MODEL_DIR` | каталог весов нейросети и памяти заказов в ML-сервисе, `/models` |

Файл `.env` в Git не попадает. Не публикуйте `APP_SECRET_KEY`, пароли и токен бота.
